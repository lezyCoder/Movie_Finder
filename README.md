# 🎬 Dekho Movie - Movie Search Application

A modern movie search application built with React that allows users to search for movies, view detailed information, and save their favorites.

## 🌟 Features

- **Movie Search**: Search for any movie using the OMDB API
- **Movie Details**: Click on any movie to view comprehensive details including plot, cast, ratings, and more
- **Favorites**: Save your favorite movies for quick access
- **Similar Movies**: Discover similar movies based on your current selection
- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Modern UI**: Clean, Netflix-inspired dark theme interface

## 🚀 Live Demo

[View Live App](https://movie-finder-7a4x.vercel.app/)

## 💻 Technologies Used

- **React** - Frontend framework
- **React Router** - Navigation and routing
- **OMDB API** - Movie data
- **CSS3** - Styling and responsive design
- **Vercel** - Deployment and hosting

## 📦 Installation
```bash
# Clone the repository
git clone https://github.com/lezyCoder/movie-finder.git

# Navigate to project directory
cd movie-finder

# Install dependencies
npm install

# Create .env file and add your OMDB API key
VITE_OMDB_API_KEY=your_api_key_here

# Start development server
npm run dev
```

## 🔑 Getting an API Key

1. Visit [OMDB API](http://www.omdbapi.com/apikey.aspx)
2. Sign up for a free API key
3. Add the key to your `.env` file
